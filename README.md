# Kryptos-Terra_FDSI
Kryptos-Terra es una solución de seguridad en tres capas diseñada para proteger el ciclo de vida de Terraform. Este repositorio contiene el caso de estudio de S.A.M.J. Global Services, demostrando la prevención de fugas de credenciales en Git, el escaneo automatizado en CI/CD y la gestión centralizada de secretos.
